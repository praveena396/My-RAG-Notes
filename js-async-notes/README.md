# JavaScript Async + Node/Express Notes

Revision notes covering callbacks, Promises, `async/await`, the event loop, Web APIs vs Node, and the Express controller patterns used in the airbnb project.

| File | Use it for |
|---|---|
| [WRITE-IN-COPY.md](WRITE-IN-COPY.md) | The short version to handwrite in a notebook |
| [FULL-NOTES.md](FULL-NOTES.md) | Full explanations with a worked example for every idea |
| [PROMISES-DEEP-DIVE.md](PROMISES-DEEP-DIVE.md) | Everything about Promises: every way to create and use them with `.then` and `await`, errors, parallel vs sequential, loops, Express. Ends with a write-in-your-copy section |
| [PRACTICE.md](PRACTICE.md) | Questions with answers hidden, to test yourself after each section |

## Suggested routine

1. Read a page of `FULL-NOTES.md`.
2. Handwrite the matching page from `WRITE-IN-COPY.md`.
3. Close both and answer the matching set in `PRACTICE.md`.
4. Reread anything marked ⭐ that you got wrong.

Pages marked ⭐ are the topics that needed the most explanation: arrow function `return`, `.map` vs `.forEach`, Promises and `resolve`, `async/await`, `fetch` vs `setTimeout`, and `res.render`.
